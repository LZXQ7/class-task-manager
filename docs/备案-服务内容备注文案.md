# 小程序备案 · 备注（服务内容）填写包

> 项目：班级任务管理（微信小程序）
> 主体：个人主体 · 非经营性
> 适用：备注必填项，字数 20–200 字

---

## 一、主推文案（188 字，直接复制）

```
本小程序为非经营性个人自用日程效率工具，供本人及经授权的固定小团队成员使用。用户自行录入每周日程与时间区段，系统按轮转规则自动生成本周事务（值日）安排表，并提供今日待办提醒、完成确认、请假与换班申请记录、次数统计、日历提醒及排班表导出。小程序仅提供上述日程与事务安排的工具功能，不涉及需前置审批的互联网信息服务，不含电商、支付、广告、社交及用户自由发布内容功能，不从事经营性活动。
```

---

## 三、为什么这么写

| 写法 | 原因 |
|---|---|
| 用"非经营性 / 自用 / 不从事经营性活动" | 个人主体不得涉及经营性业务，备注里出现"经营服务""销售"会被打回 |
| 用"日程 / 时间区段 / 事务安排"替代"课程 / 教学 / 培训" | 教育、培训类需前置审批，命中关键词会被要求补承诺书甚至驳回 |
| 用"固定小团队成员"替代"班级 / 同学" | 语义等价但避开校园教育联想，与实际功能（值日排班）不冲突 |
| 明确列出"不含电商、支付、广告、社交、UGC" | 主动划清边界，审核员一眼能判定无需前置审批，通过率更高 |
| 全篇不出现公司名、单位名、官网字样 | 福建明确禁止"XX公司官网、XX单位旗下产品"类表述 |

## 四、同批要填的其他字段（口径要一致）

| 字段 | 建议填写 |
|---|---|
| 服务内容标识 | 工具类相关（如「工具 → 效率」），**不要选教育** |
| 互联网信息服务前置审批项 | **以上都不涉及** |
| 小程序名称 | 避开"教育/培训/校园/学院/课堂"，建议"值日小助手""排班助手"等 |
| 小程序简介 | 与备注口径一致："班级日程与值日安排工具" |
| 类目（mp 后台） | 工具 → 效率 |

## 五、提交后必盯的三件事

1. **12381 短信核验**：平台初审通过后，工信部发验证码，**24 小时内**登录 beian.miit.gov.cn 完成核验，超时自动驳回、全部重来。
2. **应急联系电话**：不能与本人手机号、小程序负责人手机号相同。
3. **福建专属**：个人备案时主体负责人与小程序负责人必须为**同一人**。

## 六、地区特殊格式（如适用需改写）

- **天津**：备注须声明"小程序应急电话使用人为XXX，与主办者的关系为XXX（须直系亲属）"，且主体备注留空。
- **广东**：小程序昵称为非纯中文时，须在备注注明中文名称 + 主要服务内容，文末加"承诺遵守中华人民共和国法律法规。"
