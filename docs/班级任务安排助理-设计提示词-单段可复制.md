你是一名资深的微信小程序 UI 设计师。请为「班级任务管理」生成全套高保真界面。

【产品是什么】
面向大学班级的「课表驱动的轻量值日协作工具」。生活委员一键生成本周值日排班，同学打开小程序就在首页看到「今天第几节、你值日、在哪间教室」，并可确认完成、申请换班或请假。单班自用，60 人以内。不做社交、不做内容平台、无支付、无拍照打卡、无任何用户自由输入的文本内容。

【视觉关键词】
极简、轻量、克制。单一主色、大留白、细描边、几乎无投影。像一张干净的课程表，不像社交 App。
