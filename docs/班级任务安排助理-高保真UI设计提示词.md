# 班级任务管理 · 高保真 UI 设计提示词 v1.0

> **交付物**：一份可直接粘贴给 AI 设计工具（Figma AI / Motiff / MasterGo AI / 即时设计 AI 等）的高保真界面生成提示词。
> **画布**：375 × 812 px（iPhone X 逻辑分辨率），微信小程序竖版，1px = 2rpx。
> **产品定位**：面向大学班级的「课表驱动的轻量值日协作工具」。视觉关键词：**极简、轻量、克制、单主色、大留白、轻描边重投影**。
> **用法**：第 0–3 章为全局约束，**每次生成页面时必须连同第 0 章 + 第 2 章 + 第 3 章 + 目标页面章节一起提交**；第 4 章每页可单独抽取。

## 0. 元指令（每次生成都必须带上这一段）

```
你是一名资深微信小程序 UI 设计师。请基于下面的设计规范，为「班级任务管理」生成高保真界面。

硬约束：
1. 画布 375×812px，竖版，iOS 风格，微信小程序环境。
2. 整体风格极简轻量：单一主色 #3370FF，页面底色 #F5F6F8，卡片纯白 + 1px 极浅描边，禁止重投影/渐变滥用/玻璃拟态/霓虹色。
3. 禁止使用 emoji 充当图标。所有图标为 2px 线性描边、24×24 网格、圆角端点，统一线性图标家族。
4. 无用户头像与图片素材：人物用「姓名首字圆形色牌」代替。全站零摄影图、零插画风人物，空状态仅允许使用极简几何线稿插画。
5. 中文字体 PingFang SC，英文/数字 DIN Alternate 或系统字体，数字使用等宽（tabular）。
6. 严格使用本提示词给定的尺寸、间距、字号、色值，不得自行放大圆角或加深阴影。
7. 每个页面输出为一个独立 Frame，命名格式：`P编号-页面名`，Frame 内使用自动布局（Auto Layout），层级命名规范为「模块/元素」。
8. 同一元素在不同页面必须尺寸、圆角、色值完全一致（见第 3 章组件库），不得临场重绘。
9. 除正常态外，必须同时输出该页标注的异常态、空态、加载态、禁用态（各占一个子 Frame 或变体 Variant）。
```

## 1. 项目概览与页面地图

### 1.1 一句话定位
把生活委员每周手搓 Excel 的 30 分钟，变成一键生成的 30 秒；把同学「今天要不要扫地」，变成打开就看见的一张卡片。

| 普通同学 | ~55 | 首页、课表（只读）、值日表（只读已发布）、我的 |

## 10. rpx 换算速查（开发落地用）

设计稿 375px 宽 = 750rpx，**1px = 2rpx**。字号与间距直接 ×2 即可（如 16px → 32rpx，48px 按钮高 → 96rpx）。
状态栏、TabBar 需在 JS 中读取 `wx.getSystemInfoSync()` 的 `statusBarHeight` 与安全区做动态适配，设计稿按 44 / 34 出图。
