## ⚠️ 提审前必做：mp 后台「审核备注」填这段 + 为本次提审重新开启审核体验入口

（说明：每个版本都要走审核，所以审核体验入口需为本次提审**重新开启**。强烈建议换**新**口令，不要复用上一版 `LXQ-L3SS-CGHQ-DUWG-T5`。）

审核驳回原文要求「在首页填写有效账号及密码」。本小程序**没有账号密码体系**（采用「班级口令 → 名单选人 → 学号后 4 位」绑定），  
故继续提供**审核体验入口**：审核员在首页「审核体验入口」输入下列口令即可一键进入**体验账号**（完整功能可体验）。

请把下面整段复制到 mp 后台本次提审的**审核备注 / 体验账号**栏位：

```
体验入口：首页底部「审核体验入口」
体验口令：LXQ-R4KD-8W2X-M9PN-5T
说明：本小程序为班级内部管理工具，常规绑定需班级口令与本人学号，审核员无法自行获取；
      故提供上述审核体验入口，输入口令后可进入体验账号，值日表、课表、请假、排班等主要功能均可完整体验。
      该入口仅在审核期间开启，审核通过后即行关闭（且本口令仅本次提审有效，下次提审前须换新口令）。
```

开启体验入口（在线上库执行，class id=3；口令用上面新值；并给演示账号打「演示态」标记）：

```sql
UPDATE `class` SET review_demo_on = 1, review_demo_code = 'LXQ-R4KD-8W2X-M9PN-5T' WHERE id = 3;
UPDATE member SET is_review_demo = 1 WHERE id = 69;   -- 体验超管（000000000091）
```

> 🛡️ **演示态行为（本版新增的安全口径）**：审核员进入后，值日与换班、课表查看与编辑、请假登记、排班、通知等**所有主功能可完整体验**；仅对「删成员 / 停用 / 解绑他人 / 授予职位 / 班级管理 / 清空通知 / 发全员公告 / 课表全量导入」等**破坏性动作**会提示「演示模式：该操作不会真实执行」（**不会改动任何真实数据**）。降权但不缺功能。
>
> ⚠️ 口令**不要**写进小程序前端（会随包泄露），只填在 mp 后台 + 上面的 `class.review_demo_code`。**审核通过后必须关闭**，见文件末尾「关闭方式」。  
> 🔒 口令安全：本版已落地「**缩小权限面**」（演示态拦截破坏性动作）；其余加固（自动过期 / 哈希存储 / 强制轮换）见 `outputs/审核口令安全加固方案.md`，建议下个版本落地。

### 审核通过后：关闭体验入口（务必执行）

否则等于在公网留了一个「知道口令就能当超管」的通道：

```sql
UPDATE `class` SET review_demo_on = 0, review_demo_code = '' WHERE id = 3;
UPDATE member SET is_review_demo = 0, openid = NULL WHERE id = 69;   -- 体验超管（000000000091）
```

关闭后：首页不再渲染「审核体验入口」（`wx:if="{{reviewOn}}"` 恒假），线上表现与 1.0.6.3 关闭态一致。
