# 系统功能完整介绍（按页面顺序）

> 本文档按 `app.json` 注册顺序，从首页开始，逐页说明每个页面的功能模块、交互细节、提示文案、状态变化与边界处理，覆盖所有容易被忽略的小功能点。全部内容均基于小程序源码（`miniprogram/pages/**`）逐页核查。
>
> 角色模型贯穿全文：**普通成员 / 班委（生活委员、班长等）/ 超级管理员（超管）/ 辅导员（groupTag='X'）**。

## 一、首页 `pages/home/index`（Tab 1 · 底部第 1 个标签）

**用途**：今日聚合页。按身份展示「值日提醒 / 今日·明日课次 / 作业提交播报 / 请假看板」，并提供语音通知、扫码、查看班级/通知/作业等快捷入口。

**入口**：tabBar 首屏；未绑定用户首屏即引导去绑定。

**功能模块（视觉从上到下）**
- **顶部日期条**：显示 `dateText`（如「10月29日 周四」）+ `weekText`（「第 N 周」）。
- **模拟态护栏条**：`impersonateBanner` 非空时显示红色横幅，含「恢复本人」按钮（`onRecoverSelf`），仅开发者演示账号可见，正常用户不显示。
- **作业提交播报**：`hwFeedShow` 时滚动「张三 提交了《XXX》」，点击跳作业页并记游标（首次仅记基线不播，最多播 5 条、每条 2.4s，播完自动收起）。
- **今日值日 Hero 卡**（非辅导员才渲染）：显示 `periodText`（第几节）、状态（待值日/进行中/已结束/已请假/已换出，进行中带呼吸动效点）、同行同学头像与「查看详情 ›」；无值日时显示「今天没有你的值日 / 可在『值日』页查看本周安排」。
- **今日课次卡**：按组过滤去重渲染，每行时间/教室、课程名、标签「A 组」「B 组」「全体」「选修」；本人课带蓝色竖条；带 `canCourseInfo` 权限的行可点开「课堂情况」弹窗（选修课不弹）；无课显示「今天无课🎉」；已过下课时间整行灰化。
- **明日课次卡**：结构同上，标题旁多一行明天日期；无课显示「明日无课🎉」。
- **首页请假卡**（`showLeaveHome`，班委/超管/辅导员可见）：显示「x 人当前请假 / 今日共 N 人请假 / A 组 N 人 / B 组 N 人 / 查看名单 ›」；辅导员模式显示「各班请假人数」+ 按班列表。
- **快捷入口**：查看班级（超管/辅导员）、成员与分组、查看通知（带未读角标 `noticeUnacked`）、作业。
- **语音通知条**：`unreadNotice` 有时显示播放/暂停（`onPlayNotice`）。
- **底部扫码**：`onScan`，支持 `N\d+` 通知音频二维码、纯数字通知 id、scene 跳转绑定页三种分支。

**状态与边界**
- 未绑定 → empty-state「你还没有绑定班级 / 立即绑定」→ 跳绑定页。
- 网络失败 →「数据没加载出来 / 检查网络后重试 / 重新加载」。
- 加载中 → 骨架卡 + 列表骨架。
- 辅导员视角隐藏 Hero、今日/明日课次、语音胶囊。
- 课堂情况弹窗仅 `canCourseInfo`（班长/副班长/超管且非辅导员）；文本唯一真源 `courseInfoText`，「复制课堂情况」按钮提示「已复制，去群里粘贴吧」；班级名三层兜底（真名→本班名→「(班级)」）。

**易忽略小功能**
- 作业播报游标键 `hwfeed:meId:classId`，切走停表不记游标。
- 身份指纹 `_identityFp` 变化、换班/名册/全局 `viewClassId` 变化均强制重拉。
- 课次 `wx:key` 用 JS 预生成 key（全班 `s<id>`、选修 `p<pid>`），避免选修课 `sessionId=0` 撞键。
- 下拉刷新（`onRefresh`）、实时定时器按 12:00/18:00/00:00 及请假时段边界翻面、课次灰化定时。
- `onHide`/`onUnload` 已合并清理定时器，防泄漏。

## 二、课程表 `pages/timetable/index`（Tab 2 · 底部第 2 个标签）

**用途**：展示本周课表，支持切周/切班（辅导员/超管）、A/B/全组/临时调课筛选，长按调课（超管）、课次详情与新增/编辑。

**功能模块**
- 导航栏右侧「校历」按钮（仅 `isSuper && hasTimetable && !isCounselor`）。
- `week-switcher` 切周；`fab` 菜单：A组/全部/临时调课（临时调课仅超管）。
- 辅导员/超管显示切测试班 chips。
- 课表主体：左侧节次列固定，右侧日期+格子横向滚动；格子标签「选修」「A 组」全体，含假/班/调/入标记。

**状态与边界**
- 学生无课表 →「课表待接入教务系统」；辅导员无绑定班 →「暂无可查看的班级」；所选班无课表 →「该班还没有课表」。
- 加载骨架跟随节次；失败 →「课表没显示出来 / 请重启小程序后重试」。

**交互与边界**
- 长按 `onCellLongPress` 调课（超管）：空格提示「这个格子没有课，长按无效」；非超管提示「只有超级管理员可以临时调课」。
- 课次详情 bottom-sheet；新增/编辑课次表单：课程名/教师/教室 placeholder、课程类型 segmented、上课分组 chips、上课时间 chips、周次 chips、每次需值日 stepper 0–4。
- 个人选修课最多 2 门 →「个人选修课最多添加 2 门」；课程名必填 →「请填写课程名」。
- 临时调课四 tab（本周/多周/按日期/AI）：「已保存，值日请重新生成」「请选择课次/请选择要调整的周次/请先选择要取消的日期/请先说说要怎么调课」；AI 调课「AI 没有给出需要调整的课次 / 已应用 AI 调课方案」；「已撤销本周全部临时调课」；跨周调课弹确认框。

**易忽略小功能**：左右滑动切周手势（`utils/swipe`）；tab 入场动画档位；切班仅辅导员/超管；校历仅超管且非辅导员。

## 三、值日 `pages/duty/index`（Tab 3 · 底部第 3 个标签）

**用途**：本周值日安排查看与排班管理（超管/生活委员可清空、一键生成、发布、撤回）。

**功能模块**
- `week-switcher`：状态文本「已发布 / 草稿 / 已归档」。
- 辅导员班级筛选 chips。
- 排班操作区（`canSchedule`）：清空值日表 / 一键生成 / 发布给全班 / 撤回发布。
- 按日合并行展示，`myDuty` 高亮，410 保洁标签「410」，`status-pill` 状态。

**状态与边界**
- 骨架 / 失败「数据没加载出来」/ 未发布「本周值日还没发布」/ 无排班「本周没有排班」/ 正常。
- 已结束 N 天弹层（`endedSheetShow`）。

**交互与边界**
- 加值日生弹层、本人值日 `duty-sheet`、合并行成员弹层。
- 提示「这一天没有可安排的课次」「该同学已在这个课次」。
- 文案「已添加 / 本周值日已发布 / 已撤回发布 / 已清空，可重新生成」。
- 一键生成 AI 弹层：`textarea maxlength 600`，按序号轮转/AI 生成，自检；排班方式（岗位槽/主教室/18:10保洁）。
- 校验「请至少勾选一天 / 请至少添加一个打扫日」「已保存，下次生成生效」。
- AI「AI 没有给出可用的排班，请换个说法」；操作超时看门狗「上一个操作还在进行，请稍候 / 操作超时，已恢复，请重试」；「七天都已经有了」。

**易忽略小功能**：`page-meta` 滚动锁；tab 入场动画；发布态同步底部 tab；防重复点击看门狗。

## 四、我的 `pages/mine/index`（Tab 4 · 底部第 4 个标签）

**用途**：个人中心——用户信息、值日统计、换班待办、AI 排班设置、外观（深色模式）、关于、班费总额。

**功能模块**
- 用户信息卡：头像（空 button 技术实现）、姓名、已绑定/体验中、`studentNoMasked·组`、辅导员显「辅导员」、职位头衔 `selfTag`（金/蓝/青，由 `util.roleTag` 推导）。
- 统计卡（非辅导员）：本学期/待值日（红色 warn）/已结束，可点开 `dutyListShow` 列表。
- 管理卡（`isAdmin || switched`）：换班待确认（角标 `pendingCount`）、发送更新公告（超管）、更多。
- 外观卡（`themeEnabled`）：深色模式三态（跟随系统/浅色/深色）。
- 关于卡。

**状态与边界**
- 辅导员整块统计卡不渲染；`loading` 初始骨架；SWR 缓存先回填旧值再后台重拉。
- 弹层：更多/关于/更新公告/AI 排班/值日明细/班费总额（`segmented` 班费⇄团费）。

**交互与边界**
- 头像：`onChooseAvatar` 上传云存储→`updateAvatar`；失败回落姓氏色块；隐私未声明兜底「打开头像选择失败，请稍后再试」。
- 切换测试账号（`onSwitchAccount`）：ActionSheet 显示「(辅导员)/(X 组)·超管」；无可选时「没有可切换的测试账号」。
- 切换体验版/正式版（`onSwitchDemo`）：弹「切换为体验版？…」；`onBackToLogin`（仅 `isTrial`）清演示回登录页。
- 绑定入口开关（`onToggleBind`，仅超管）：「开放班级绑定入口？/关闭班级绑定入口？关闭后新成员将无法绑定」。
- 关于：ICP 备案号点击复制 →「已复制工信部查询地址」。
- 值日明细 `onShowDutyList`：`type=pending/past`，防连点；状态映射 待值日/进行中/已过期/已值日；保洁课次显「18点前」。
- AI 排班：`AI_PROVIDERS` 预设 DeepSeek/智谱/通义；`onAiPreset` 一键填地址；`aiKey` 只输入不回显；`onAiTest`「连通正常（HTTP x）」；`onAiClear` 二次确认「清除后密钥无法恢复…」。
- 待确认换班：待我确认/我的申请，同意/拒绝/撤销；`canAgree` 仅 `canSchedule && direction==='out'`。
- 更新公告 `onAnncSend`：`confirmStrict`「版本 X『版本更新公告』：发送后所有人下次打开…确认发送？」。
- 深色模式 `onThemePick`：复用 nav-bar 圆形揭示动画，圆心用点击坐标。

**易忽略小功能**
- 换班操作后同步底部「值日」tab 红点 + 置 `swapDirty`/`dutyDirty`。
- 班费总额行「班费 ¥N · 团费 ¥N」，保存后同步。
- 下拉刷新；入场动画 `animSeq` 0→1/2 轮换。
- 班费总额权：`feeCanSetTotalClass`（超管/生活委员）、`feeCanSetTotalLeague`（超管/班长兼团支书）；AI 密钥跟随本人、明文不回显。

## 五、班级信息 `pages/classinfo/index`（Tab 5 · 底部第 5 个标签）

**用途**：班级聚合入口——概况 + 班级成员/班费/通知/作业四个子卡。

**功能模块**
- 班级概况 hero：总人数/A组/B组；`canManageClass` 显「班级管理」入口；`classChips>1` 显「切换 ⌄」弹层选班。
- 四个子卡：班级成员(roster)/班费（「当前班费 ¥N」）/通知（带未读角标且非其它班）/作业。

**状态与边界**
- 空态/加载；切班弹层高度按班级数算；其它班 `isOtherClass`：通知/作业只在本班带 classId。

**交互与边界**

- `_applyClass` 同步全局 `viewClassId`；`onOpen` 按 key `navigateTo`，notice 带 classId、其余仅其它班时带。

**易忽略小功能**：切班联动全站 `viewClassId`；成员统计与首页/名册口径同源。

## 六、班费 `pages/fee/index`（二级页）

**用途**：班费/团费余额与消费明细管理。

**入口**：班级信息「班费」卡 `navigateTo`。

**功能模块**
- 班费/团费切换 `segmented`（团费仅 `showLeagueCard` 有权限者可见）。
- 辅导员跨班 chips（`feeClassList>1`）。
- 余额卡：当前余额 / 总额 / 已消费。
- 消费明细：金额/备注/操作人/时间/图片，管理人可追加图片（<9）/删除。
- 增加消费表单：金额 `type=digit`、备注 `maxlength 200`、凭证图最多 9 张。

**状态与边界**
- 未绑定/失败/骨架/正常；团费卡显隐按权限。

**交互与边界**
- 删除记录 `wx.showModal`：「删除后余额会回退，且图片会一并删除，确定吗？」。
- 提交校验「请填写大于 0 的金额」；图片最多 9 张 →「图片最多 9 张」。
- 班费团费一次性拉取，切换不重拉，2s 去重窗口。
- 图片追加上限 9；金额格式化去尾零。

**权限**：`feeRights` 判定；删除需管理权；跨班仅辅导员。

## 七、绑定 `pages/bind/index`（三步流程）

**用途**：班级绑定三步（口令 → 选人 → 学号验证）。

**入口**：未绑定用户 reLaunch；首页「立即绑定」；扫码 scene。

**功能模块**
- Step0：班级口令 `maxlength 12`，placeholder「班级口令或邀请码」，过滤非字母数字转大写；「下一步」（token≥4 且已同意且非校验中）；「扫描班级邀请码」；教职工模式「我是老师/辅导员」→8 位绑定码 `maxlength 8`；「一键体验（无需口令）」；隐私协议勾选（`catchtap` 不改勾选态）。
- Step1：选身份（名单分组 A/B/教职工，搜索，已绑定标记，「就是我」）。
- Step2：学号后 4 位（4 格 `type=number maxlength 4`，「完成绑定」）。

**状态与边界**
- `bindClosed` →「班级绑定暂未开放，请联系管理员开启后重试」。
- 验证次数过多（`errCode 40005`）→「验证次数过多…请稍后再试或联系生活委员手动绑定」。

**交互与边界**
- `onTokenInput` 过滤；`onNext` 并行校验+拉名单。
- 绑定成功「绑定成功，欢迎加入」→ switchTab 首页。
- 学号错误「学号后 4 位不匹配，你还有 N 次机会」。
- `onQuickDemo` 演示班；`onStaffSubmit` 教职工绑定；`onDoc` 跳 doc 页。

**易忽略小功能**：`ROSTER_CACHE` 内存缓存；教职工 8 位一次性码；防爆破锁（24h 累计失败≥500 由超管在「我的」开回）。

## 八、手动排班 `pages/manual/index`（二级页）

**用途**：把同学手动安排到某节课次（含空课次），超管/生活委员专用。

- 底部固定条「共 N 次值日 · N 人」/ 发布给全班 / 撤回发布。

**交互与边界**
- `onMemberTap` `wx.showActionSheet['换人','移除值日']`。

**易忽略小功能**：底部条实时计数；发布态写云函数；`canSchedule`（超管|生活委员）真拦截在 `scheduleAuth`。

## 十、通知列表 `pages/notice/index`（二级页）

**用途**：查看班级通知、确认收到、左滑删除、回收站、图片查看器。

**入口**：首页「查看通知」/班级信息「通知」（`?classId=&name=`）。

**功能模块**
- 顶部「开启服务通知」提示条 `showSubTip`（微信订阅消息授权）。
- `canPublish` 显示「发布通知」入口。
- 骨架/失败「通知没加载出来」/空「还没有通知」「这个班还没有通知」。
- 通知卡：左滑露删除区「删除」；标题、`needAck` 时「已收到/待收到」、meta（发布人·时间·scope）；正文折叠「展开全文/收起」+ 箭头旋转；外链「点击打开」；配图缩略图（`nt-viewer` 预览）；回执（`canSeeAck`「已收到 N」、`seq` 芯片、`canAck`「确认收到」）。
- 清空全部（`canClear` 测试超管）；回收站常驻 `nt-trash`（`recycleCount` 角标，`trashPulse`）；回收站弹层（清空/恢复）。
- 图片查看器（左右导航/圆点 shared-element）。

**状态与边界**
- 按班查看（`viewClassId`）显示「示例班级C · 通知」；超管 `canClear`；`canPublish` 超管/班委/辅导员；`canSeeAck` 班委可见回执。

**交互与边界**
- 左滑手势：`onSwipeStart/Move/End`，`BTN_WIDTH=88`，滑过半吸附。
