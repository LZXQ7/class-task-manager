## 版本 A：提审版（mp 后台「版本描述」用，功能枚举、言简）

1. 「班级信息」更名为「信息」（Tab 与导航栏一致），页面精简为班级概况、班级成员、班费三个入口。
2. 新增「倒数日」：可在本页记录自定义重要节点（事件名 + 目标日期，本地保存），自动按最近排序显示「还剩 N 天 / 今天 / 已过 N 天」，纯本地、不上云。
3. 移除信息页「通知」「作业」两个子卡入口及相关逻辑。
4. 修复交互问题：弹层底部按钮不再被底部导航栏遮挡；弹层左上角穿透显示的主题图标已隐藏；普通成员不再显示「切换班级」入口；倒数日卡片移至班级概况正下方。
