# v1.0.6.8 更新说明（班费 / 团费 + 「我的 → 更多」入口收纳）

> 覆盖范围：**1.0.6.5 → 1.0.6.8**（2026-10-15）的用户可感知改动。
> ⚠️ **1.0.6.7 的前端此前未上传**（仅云函数部署生效），故本版一并携带 1.0.6.7 的全部前端改动。
>
> **本版新增（1.0.6.8）**：
> ①**班费 / 团费模块** —— 首页按权限展示班费卡（团费卡仅超管与班长兼团支书可见），可查看余额、总额与已消费，登记消费（金额 + 备注 + 最多 9 张凭证图片）、删除消费记录；
> ②**总额设置** —— 「我的 → 更多 → 班/团费总额」，分段控件滑动切换班费 ⇄ 团费后编辑（班费：超管 / 生活委员；团费：超管 / 班长兼团支书）；
> ③**「我的」页新增「更多」入口** —— 切换测试账号、班级绑定入口、AI 排班设置、手动排班四项收纳其中；
> ④**首页管理员入口位置调整** —— 「成员与分组 / 发布通知」移至「本班请假」下方；
> ⑤**修复** —— 设置总额后首页余额刷新滞后，改为进页面即刷新；
> ⑥**首页课次行视觉** —— 名称与时间 / 教室列间距收紧、过长自动两行显示、靠上对齐；
> ⑦**审核体验入口改为超管开关** —— 「我的 → 审核体验入口」一键开 / 关，**开启时由系统自动生成一条新的仅预览口令**（旧口令当场作废，不再需要跑 SQL、也不用手写口令），弹层里可复制去填 mp 后台审核备注。
>
> **随本版一并携带（1.0.6.7，此前未上传前端）**：
> ⑦值日课次**下课 10 分钟**即标「已值日」；⑧班级「**主教室**」配置（保洁按该房间走，改主教室自动同步课次名与房间）；⑨**大节数跟随班级时间配置**（不再固定 5 节，可加 45 分钟等短课，值日人数填 0 = 不排值日）；⑩课次「**具体周次**」支持区间写法 `6-13`；⑪课表详情值日人数显示真实值、后台「第 x 节」不折行、值日页移除「+ 加值日生」快捷入口。
>
> **云函数**：1.0.6.7 的 13 个函数**已全部部署生效**；本版**新增 `fee` 云函数（已部署）**与 `class_fund` / `class_fund_record` **两张表（已建）**，`auth` 因新增体验入口开关**已重新部署**。**前端需在微信开发者工具「上传」**（上传前先点一次「编译」）。

## ⚠️ 提审前必做：先在小程序里开开关拿口令，再填 mp 后台「审核备注」

> 🆕 **本版起流程变了**：以前是「我在更新说明里手写一条口令 → 你跑 SQL 写库」。
> 现在**口令由系统在开启那一刻自动生成**，只回显给超管本人 —— 每次提审都是新的一条，不用再跑 SQL、也不会误用旧口令。

**第 1 步（在小程序里，用超管身份）**：「我的 → 管理 → 审核体验入口」→ 点「开启」→
弹层里出现本次的体验口令 → 点「复制口令」。
（开启会作废旧口令；审核期间若忘了口令，点行尾「口令」按钮可**再看一次**，**不会**换口令、也不会把审核员踢下线。）

**第 2 步（mp 后台）**：把复制到的口令填进下面这段，整段粘到本次提审的**审核备注 / 体验账号**栏位：

```
体验入口：绑定页底部「审核体验入口」
体验口令：<第 1 步复制出来的那条，形如 LXQ-XXXX-XXXX-XXXX-XXXX>
说明：本小程序为班级内部管理工具，常规绑定需班级口令与本人学号，审核员无法自行获取；
      故提供上述审核体验入口，输入口令后可进入体验账号，值日表、课表、请假、排班、班费与团费等主要功能均可完整体验。
      该入口仅在审核期间开启，审核通过后即行关闭（口令为系统随机生成、每次开启都会更换）。
```

> 🛡️ **演示态行为**（1.0.6.4 已落地的安全口径，本版沿用）：审核员进入后，值日与换班、课表查看与编辑、请假登记、排班、通知、班费与团费等**所有主功能可完整体验**；仅对「删成员 / 停用 / 解绑他人 / 授予职位 / 班级管理 / 清空通知 / 发全员公告 / 课表全量导入」等**破坏性动作**会提示「演示模式：该操作不会真实执行」（**不会改动任何真实数据**）。降权但不缺功能。
> 🛡️ **演示身份不能自己动这道开关**：`auth.reviewDemoSet` / `auth.reviewDemoStatus` 已进演示态拒绝清单，审核员就算拿到超管身份也换不出新口令。
>
> ⚠️ 口令**不要**写进小程序前端（会随包泄露），只在弹层里回显给超管本人。**审核通过后必须关闭**，见文件末尾「关闭方式」。
>
> 🔧 **开关万一不可用时的兜底**（等同于手动开关，需 `UPDATE` 权限）：
> ```sql
> UPDATE `class` SET review_demo_on = 1, review_demo_code = '<自拟口令>' WHERE id = 3;
> UPDATE member SET is_review_demo = 1 WHERE id = 69;   -- 体验超管（000000000091）
> ```

## 版本 A：提审版（mp 后台「版本描述」用，功能枚举、言简）

1. 新增班费与团费模块：首页按职位权限展示班费卡片（团费卡片仅超级管理员与班长兼团支书可见），可查看余额、总额与已消费金额，登记消费时可填写金额、备注并上传最多 9 张凭证图片，已登记的消费记录可删除。普通成员可查看班费余额，但不可进行操作。
2. 新增班费与团费总额设置：入口位于「我的 → 更多 → 班/团费总额」，进入后通过分段控件滑动切换班费与团费，分别设置总额。班费总额由超级管理员与生活委员设置，团费总额由超级管理员与班长兼团支书设置。余额由系统按「总额减已消费」实时计算。
3. 「我的」页面新增「更多」入口：将切换测试账号、班级绑定入口、AI 排班设置、手动排班四项功能收纳其中，管理卡片界面更简洁。
4. 首页管理员入口位置调整：「成员与分组」与「发布通知」两处入口移至「本班请假」下方，排列顺序更符合使用频率。
5. 修复一项显示滞后问题：设置班费或团费总额后，首页余额需要等待较长时间才更新，现调整为进入首页即重新获取最新数据。
6. 首页课次显示优化：课程名称与时间、教室列的间距收紧，课程名称过长时自动以两行显示并省略超出部分，整体靠上对齐，不再出现显示不全的情况。
7. 值日状态口径调整：一节课结束后 10 分钟即自动标记为「已值日」，不再需要等待下一节课开始；下午无课时段也能正常显示已完成状态，避免长时间停留在「进行中」。
8. 班级新增「主教室」配置：网页管理后台可为每个班设置主教室，保洁值日按该房间执行（周一至周五的打扫与周二的大扫除自动同步），更换主教室后历史值日记录同步显示新房间，无需重新排班。
9. 课表大节数放开限制：由固定 5 节改为跟随班级时间设置，可添加 45 分钟等短时课程；课次的「每节值日人数」支持填写 0，表示该课次不参与值日排班。课表网格行数随周次自适应，仅当该周确有短课安排时才多显示对应行，不再出现整行空格子。
10. 课次的「具体周次」支持区间写法（例如填写 6-13 表示第 6 至第 13 周），此前区间写法只取到起始周、其余周不显示该课次。课表详情中的「每节值日人数」按实际配置显示，设置为 0 的课次不再显示为 2 人。
11. 显示与交互修正：首页「今日课次」课程名称对齐；网页管理后台课程表「第 x 节」不再折行；值日页移除每天下方的「+ 加值日生」快捷入口，该操作由每行右侧的「调整」承担。
12. 审核体验入口改为超级管理员可自主控制的开关：入口位于「我的 → 审核体验入口」，开启时由系统自动随机生成一条新的仅预览口令，旧口令立即失效，超管可在弹层内复制该口令用于提审；关闭后口令作废、正在体验的账号即时登出。该开关仅超级管理员可见，演示身份无权操作。
13. 本次为功能更新，服务端已同步上线，审核体验入口沿用既有机制，提审前开启开关获取新口令，审核通过后即关闭。

### 审核通过后：关闭体验入口（务必执行）

否则等于在公网留了一个「知道口令就能当超管」的通道。

**首选（不用跑 SQL）**：「我的 → 审核体验入口」→ 点「已开启 · 点此关闭」→ 确认。
后端会同时做三件事：口令作废（清空库中口令）+ 关闭开关 + 把正在体验的演示账号登出。

**等价的 SQL 兜底**（开关不可用时才用）：

```sql
UPDATE `class` SET review_demo_on = 0, review_demo_code = '';
UPDATE member SET is_review_demo = 0, openid = NULL WHERE is_review_demo = 1;
```

关闭后：绑定页不再渲染「审核体验入口」（`wx:if="{{reviewOn}}"` 恒假），线上表现与关闭态一致。
