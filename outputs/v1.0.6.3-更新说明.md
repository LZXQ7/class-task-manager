## ⚠️ 提审前必做：mp 后台「审核备注」填这段

审核驳回原文要求「在首页填写有效账号及密码」。本小程序**没有账号密码体系**（采用「班级口令 → 名单选人 → 学号后 4 位」绑定），
故提供一条**审核体验入口**：审核员在首页「审核体验入口」输入下列口令即可一键进入**体验账号**（完整功能可体验）。

请把下面整段复制到 mp 后台本次提审的**审核备注 / 体验账号**栏位：

```
体验入口：首页底部「审核体验入口」
体验口令：LXQ-L3SS-CGHQ-DUWG-T5
说明：本小程序为班级内部管理工具，常规绑定需班级口令与本人学号，审核员无法自行获取；
      故提供上述审核体验入口，输入口令后可进入体验账号，值日表、课表、请假、排班等主要功能均可完整体验。
      该入口仅在审核期间开启，审核通过后即行关闭。
```

> ⚠️ 口令**不要**写进小程序前端（会随包泄露），只填在 mp 后台。上面的口令对应库里的开关
> `class.review_demo_on=1`（已开启）。**审核通过后必须关闭**，见文件末尾「关闭方式」。

## 版本 A：提审版（mp 后台「版本描述」用，功能枚举、言简）

1. 整改审核「登录受限」问题：首页新增审核体验入口，审核员凭审核口令可一键进入体验账号并完整体验主要功能；该入口仅在审核期间开放，审核通过后自动关闭。
2. 修复值日页「已结束」入口经常失效：进入值日页时，若该周已结束却看不到「已结束 N 天」入口，多为冷启动时配置晚到所致；现改为每次进入都按真实当前周重新校准，不再需要重启小程序。
3. 修复值日页默认显示第 1 周：此前冷启动后值日页会停在「第 1 周」而非当前周，现已随真实当前周正确显示。
4. 修复首页请假弹层把多天假误标「已过时段」：跨天请假（如 10-10 至 10-11 的下午假）在首日晚间就被错误标记为「已过时段」；现改为按请假结束日期收口，只有请假整体结束（最后一天且过了结束时段）才标记「已过时段」。

### 审核通过后：关闭体验入口（务必执行）

否则等于在公网留了一个「知道口令就能当超管」的通道：

```sql
UPDATE `class` SET review_demo_on = 0, review_demo_code = '' WHERE id = 3;
UPDATE member SET openid = NULL WHERE id = 69;   -- 体验超管（000000000091）
```

关闭后：首页不再渲染「审核体验入口」（`wx:if="{{reviewOn}}"` 恒假），线上表现与 1.0.6.2 完全一致。
