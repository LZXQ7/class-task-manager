## 版本 A：提审版（mp 后台「版本描述」用，功能枚举、言简）

1. 新增班委请假登记：班委或超级管理员可在「成员与分组」页为同学按日期区间登记请假，区间内已排的值日自动标记为「已请假」，登记错了可撤销并恢复值日。
2. 新增在位人数统计并重排页面顶部：「成员与分组」页顶部改为一张卡片，分「名册概览」（总人数 / A 组 / B 组 / 已绑定）与「今日在位」（请假人数 / A组在位 / B组在位 / 全体在位，按当天计算）两组；搜索与操作按钮分行排布，当天请假的同学在名单中带「请假中」标签。
3. 修复安卓手机底部导航栏紧贴屏幕底：底栏底部留白改为「无系统安全区时兜底」，安卓与 iPhone 观感一致。
4. 修复「手动排班 → 添加值日」弹层无法上下滑动：弹层内联样式拼接缺分隔符导致固定高度失效，已修复；AI 生成、导入名单、加值日生三个同款弹层一并恢复。
5. 修复「我的」页「待值日 / 已结束」数字与弹层明细不一致：两处改为同一套口径，数字与明细条数永远一致。
6. 新增首页请假人数卡片：班委或超级管理员主页显示本班当日请假人数，点击可查看按 A/B 组分列的请假名单并撤销；辅导员主页显示所带各班的总请假人数，点击查看只读名单（不可撤销）。
7. 优化辅导员视图：辅导员进入具体班级的成员与分组页，仅展示请假人数、不展示在位统计，查看名单为只读（登记权仍在班委 / 超管）。
8. 优化请假登记交互：选人列表由「一人一行」改为头像网格图标形式，每行 4 个，更紧凑、更易点选。
9. 新增所有列表页 iOS 式 overscroll 弹性与下拉刷新：列表滚到顶或底继续下拉时内容带阻尼跟随（最多拉出 120px、绝不 1:1 跟手）、卡片轻微拉伸，松手按速度 spring 回弹；拉过阈值触发对应列表真实刷新（首页课次 / 值日周表 / 我的统计 / 绑定名单 / 弹层列表），刷新完成收起。
