# v1.0.6.5 更新说明（值日卡视觉优化 + 首页请假按时段自动刷新）

> 覆盖范围：**1.0.6.4 → 1.0.6.5**（2026-10-13）的用户可感知改动，两项均为**纯前端**：①**值日卡视觉优化** —— 合并行序号牌收小、姓名加粗放大、课次间加灰色分割线、4 人保洁自动 2×2 布局；②**首页「当前请假」按时段自动刷新** —— 卡片按请假时段起止自动翻面，`onShow` 重新拉取。  
> **云函数**：本版**未改动，无需重部署**。**前端**需在微信开发者工具「上传」（上传前先点一次「编译」）。  
> 门禁 **83/83 全绿**（`check-leave-realtime-courseinfo.js` 扩时段翻面变异；`check-wxss` / `check-wxss-compile` / `check-wxml` / `check-tuesday-clean` 全绿）。

## ⚠️ 提审前必做：mp 后台「审核备注」填这段 + 为本次提审重新开启审核体验入口

（说明：每个版本都要走审核，所以审核体验入口需为本次提审**重新开启**。强烈建议换**新**口令，不要复用上一版 `LXQ-R4KD-8W2X-M9PN-5T`。）

审核驳回原文要求「在首页填写有效账号及密码」。本小程序**没有账号密码体系**（采用「班级口令 → 名单选人 → 学号后 4 位」绑定），  
故继续提供**审核体验入口**：审核员在首页「审核体验入口」输入下列口令即可一键进入**体验账号**（完整功能可体验）。

请把下面整段复制到 mp 后台本次提审的**审核备注 / 体验账号**栏位：

```
体验入口：首页底部「审核体验入口」
体验口令：LXQ-N7K2-4M9X-P6W3-8R
说明：本小程序为班级内部管理工具，常规绑定需班级口令与本人学号，审核员无法自行获取；
      故提供上述审核体验入口，输入口令后可进入体验账号，值日表、课表、请假、排班等主要功能均可完整体验。
      该入口仅在审核期间开启，审核通过后即行关闭（且本口令仅本次提审有效，下次提审前须换新口令）。
```

开启体验入口（在线上库执行，class id=3；口令用上面新值；并给演示账号打「演示态」标记）：

```sql
UPDATE `class` SET review_demo_on = 1, review_demo_code = 'LXQ-N7K2-4M9X-P6W3-8R' WHERE id = 3;
UPDATE member SET is_review_demo = 1 WHERE id = 69;   -- 体验超管（000000000091）
```

> 🛡️ **演示态行为（1.0.6.4 已落地的安全口径，本版沿用）**：审核员进入后，值日与换班、课表查看与编辑、请假登记、排班、通知等**所有主功能可完整体验**；仅对「删成员 / 停用 / 解绑他人 / 授予职位 / 班级管理 / 清空通知 / 发全员公告 / 课表全量导入」等**破坏性动作**会提示「演示模式：该操作不会真实执行」（**不会改动任何真实数据**）。降权但不缺功能。
>
> ⚠️ 口令**不要**写进小程序前端（会随包泄露），只填在 mp 后台 + 上面的 `class.review_demo_code`。**审核通过后必须关闭**，见文件末尾「关闭方式」。

## 版本 A：提审版（mp 后台「版本描述」用，功能枚举、言简）

1. 值日卡视觉优化：值日合并行序号牌适当收小、姓名加粗放大更醒目，序号居中于姓名正上方、二字姓名与三字姓名上下对齐、列间距更紧凑；不同课次的值日之间新增灰色分割线，层级更清晰；周二「410大扫除」4 人值日自动排成 2×2 布局。
2. 首页「当前请假」卡片优化：按请假时段的真实起止时间自动刷新，时段开始与结束均能及时翻面，数字与课堂情况页保持一致；进入页面时也会重新拉取最新状态。
3. 本次为纯前端优化，云函数无需变更；审核体验入口沿用 1.0.6.4 机制，提审前已重新开启并更换新口令，审核通过后即关闭。

- **审核口令安全**：本版沿用 1.0.6.4 落地的「**缩小权限面**」——演示态拦截破坏性动作，演示身份仍可完整体验所有功能，但删除成员、修改权限等破坏性操作在演示模式下不会真实执行。其余的**自动过期 / 哈希存储 / 强制轮换**仍在 `outputs/审核口令安全加固方案.md`，建议下个版本实施。

### 审核通过后：关闭体验入口（务必执行）

否则等于在公网留了一个「知道口令就能当超管」的通道：

```sql
UPDATE `class` SET review_demo_on = 0, review_demo_code = '' WHERE id = 3;
UPDATE member SET is_review_demo = 0, openid = NULL WHERE id = 69;   -- 体验超管（000000000091）
```

关闭后：首页不再渲染「审核体验入口」（`wx:if="{{reviewOn}}"` 恒假），线上表现与 1.0.6.4 关闭态一致。
