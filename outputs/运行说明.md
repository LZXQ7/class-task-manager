# 运行说明（班级任务管理微信小程序）

> 本文件为参赛提交包的"源代码及运行说明"配套文档，面向评审快速理解如何导入、运行与验收本项目。详细工程文档见仓库内 `README.md` 与 `docs/`。

## 1. 项目概述
"班级任务管理"是一款面向高校班级日常管理场景的微信小程序，采用**自主编程**（原生小程序 + CloudBase 云函数 + 云数据库）实现，覆盖值日排班、成员与权限、班费、作业、通知、课程表、请假等模块，打通"发布—执行—确认—统计"闭环。

本仓库为**已脱敏的公开源码**，不含任何学生隐私（PII）、数据库口令、上传私钥或令牌。

## 2. 技术栈
| 层 | 技术 |
|---|---|
| 前端 | 微信小程序原生（WXML / WXSS / JS），无前端框架、无 npm 构建 |
| 后端 | CloudBase 云函数（Node.js 18 runtime） |
| 共享逻辑 | `cloudfunctions/common/` 被多个业务函数复用（真源，改动需同步） |
| 数据库 | CloudBase MySQL（TDSQL）关系型数据库 |
| 后台 | `admin-web`（Express HTTP 云函数）同源托管管理页面与 `/api/*` |
| 脚本 | Node.js（门禁 / 部署 / 验证）+ 少量 Python（排班求解、xlsx 解析） |

## 3. 环境依赖
- **微信开发者工具**（用于导入项目、预览与上传小程序）
- **Node.js 18.x**（与云函数 runtime 对齐）
- **CloudBase CLI（`tcb`）**，已登录且对目标环境有部署权限
- 一个 **CloudBase 环境**，envId 见 `cloudbaserc.json`

## 4. 源码结构（节选）
```
miniprogram/        # 小程序前端源码（pages / components / utils / data）
cloudfunctions/     # 云函数：common 共享模块 + 业务函数 + admin-web
scripts/            # 门禁 / 部署 / 验证 / 迁移脚本
docs/               # 产品、设计、接入与合规文档
cloudbaserc.json    # CloudBase 云函数与部署配置
project.config.json # 小程序项目配置（appid 等）
```

## 5. 导入与运行步骤
1. **导入前端**：微信开发者工具 → 导入项目 → 选择本仓库目录（`project.config.json` 已就绪）。
2. **本地预览**：前端为原生小程序，**无需 npm install / 构建 npm**；真机预览与上传在开发者工具内完成。
3. **部署云函数**：改动后先 `node scripts/sync-common.js` 同步共享模块，再逐函数 `tcb fn code update <函数名> --dir . --deployMode zip -e <envId>`；后台用 `node scripts/deploy-admin-web.js`。
4. **初始化数据库**：通过 `tcb db execute -e <envId> -s "<单条 SQL>"` 执行迁移（一次仅一条 SQL）；建表/初始化脚本见 `scripts/*.sql`。
5. **环境变量**：`DB_*` 等需在 CloudBase 控制台或 `cloudbaserc.json` 中按实际环境配置；本仓库不附带任何明文凭据。

## 6. 角色与权限
| 角色 | 能力范围 |
|---|---|
| 普通成员 | 查看本人排班/班费余额/作业/通知，提交作业与请假 |
| 班委 | 发布作业/通知、班费记账、配置排班规则与岗位槽 |
| 辅导员 | 跨班查看与汇总、通知确认管理 |
| 超管 | admin-web 集中管理成员、课程表、系统配置与审计 |

权限真源统一在服务端云函数内校验，前端仅做展示层适配，杜绝越权。

## 9. 常见问题
- **Q：能否直接 npm install 后本地起服务？** A：前端是小程序，必须在微信开发者工具中运行；后端为云函数，需部署到 CloudBase 环境，不支持本地独立起服务。
- **Q：数据库表如何初始化？** A：见 `scripts/*.sql` 与 `docs/` 数据结构说明，经 `tcb db execute` 特权通道逐条执行。
- **Q：为什么仓库没有 node_modules？** A：云函数依赖由部署时云端安装或随包上传，源码仓库不含依赖目录，属正常结构。
