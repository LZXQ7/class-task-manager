## 版本 A：提审版（mp 后台「版本描述」用，功能枚举、言简）

1. 首页新增「作业」快捷入口，全员可进入作业列表查看与提交班级作业。
2. 作业模块支持发布、提交、批阅全流程：班委/超管发布作业（标题、说明、截止时间、分组、图片/文件），成员提交后状态自动流转。
3. 截止时间可精确选择到小时和分钟，截止判断以设定时刻为准。
4. 发布作业时可选择「要求同学上传图片 / 文件 / 图片或文件」，学生端按类型校验，未按要求提交会被拦截。
5. 作业列表底部固定「发布作业」按钮（仅班委/超管可见），列表增多时自动避让。
6. 提交限制：单图 10MB、单文件 20MB、单次总量 50MB，图片最多 9 张、文件最多 3 个；视频走外链不进云存储。

- **作业详情四处修复（2026-10-24 深夜，用户真机截图四连反馈，前端 + 云函数已部署上线）**：
  ① **「作业附件若为图片则可点击预览」**——附件区此前无任何 bindtap，图片看得见点不着。已加 `onPreviewAttach`：`getTempFileURL` 换临时 http 链接后 `wx.previewImage` 相册预览（⚠️ cloud:// 云文件 ID 不能直接喂 previewImage，真机白屏），相册=本作业全部图片附件、从被点那张开始；图片行右侧给蓝色「预览」字提示。
  ② **「下方筛选没有用」**——`onFilter` 改了 `filter` 但 `_load` 的 payload 从不带它，后端永远按默认 all 返回，切「已交/未交」纹丝不动。已随请求带上 `filter`。
  ③ **「提交作业后按钮就消失或变成灰色禁用」**——提交后（待批阅/已完成）底部仍是可点渐变按钮。已按后端 `myStatus`+`closed` 三态化：未交→「提交作业」可点；被打回→「重新提交」可点（截止也豁免，与后端 submit 同口径）；待批阅→置灰「已提交 · 待批阅」；已完成→置灰「作业已完成」；已截止→置灰「已截止」。置灰复用全局 `.btn.disabled`（`--brand-disable`），`onOpenSubmit` 里还有一道双保险。
  ④ **「发布人员无法点击查看提交的作业，无法批量选择作业下载」**——成员行 bindtap 全绑在多选上，`onBatchDownload` 方法早在但 wxml 从未接按钮。已行点击=查看该成员提交（新弹层：图片预览/文件打开/保存全部），行尾勾选框=catchtap 多选不冒泡；名单上方新增批量操作条（已选 N 人 + 命名切换「姓名+学号/原文件名」+ 批量下载作业 + 取消）。
  门禁：`check-homework-detail-page.js` 扩至 35 断言（D5 筛选传参 / D6 附件预览换链接 / D7 提交按钮六态 / D8 行点击与勾选框分离 / D9 wxml 静态绑定），`check-homework-flow.js` 补 7 条后端断言（myStatus PENDING/DONE/REJECT、closed、files 对自己回显）；**七组变异自证全部翻红**；Chrome 无头复刻截图验证（附件预览入口/批量条/三态按钮/查看弹层，全部不贴边）。顺带修了批量下载的图片判定隐患（后端 files 行不带 kind，早先只看 kind 会让图片也走 openDocument 存不进相册）。
