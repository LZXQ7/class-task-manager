## 版本 A：提审版（mp 后台「版本描述」用，功能枚举、言简）

1. 修复课次时间：课表大节时间改为五个班统一配置，消除班级间时间不一致导致的课次错位。
2. 修复「我的」页值日明细排序：明细列表改为按课次（星期 / 节次）排序，与值日页顺序一致。
3. 修复值日状态不自动变更：新增状态机推导「已值日 / 进行中」，普通课次下课后至下一节开课前进入打扫时段、到点翻转「已值日」，保洁课次 18:00 起显示「已值日」，过期日期显示「已结束」。
4. 调整值日页同课次多人合并一行：同一节课的两 / 三人合并为一行（双 / 多名牌 + 汇总状态），点整行弹出成员列表可分别操作；按人视图不受影响。
5. 移除值日页「导出」入口：导出选择弹层与长图 / CSV 导出能力已移除，值日安排以页内展示为准。
6. 新增换班同意后实时刷新：在「我的」页同意 / 拒绝 / 撤销换班后，值日页 / 首页 / 我的页下次进入自动强刷，无需重进小程序。
7. 修复弹层顶部被小程序胶囊按钮遮挡：成员详情等高弹层（tall 档）按右上角胶囊关闭按钮的实际位置动态收缩上限，确保弹层顶沿低于胶囊、关闭按钮始终可点。
8. 调整值日页序号牌尺寸：序号圆牌改小一档，「按日合并行 / 按人视图行 / 合并行成员弹层行」三处统一，姓名与课次信息获得更多横向空间。
9. 调整值日页序号牌位置：去掉合并行多余的左缩进，序号牌左沿与其它视图对齐、列表内容更靠左更宽敞，本人行标识条同步移至左侧留白处。
10. 修复「我的」页点「待值日 / 已结束」弹层报「加载失败」：明细查询误用了不存在的列导致数据库报错，已更正；同时把同类查询写法统一为显式取用（消除列混读隐患）。
