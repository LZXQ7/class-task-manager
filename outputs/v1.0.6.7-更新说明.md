# v1.0.6.7 更新说明（值日状态口径 + 保洁主教室 + 课表节次放开）

> 覆盖范围：**1.0.6.5 → 1.0.6.7**（2026-10-14）的用户可感知改动：
> ①**值日状态口径** —— 课次在下课后 10 分钟即标记「已值日」（此前要等下一节课开始，下午无课时会一直显示「进行中」）；
> ②**班级主教室** —— 后台可配置每班主教室，保洁值日按该房间走（周一/三/四/五打扫、周二大扫除），改主教室自动同步课次名与房间；
> ③**课表节次放开** —— 大节数改为跟随班级时间配置（不再固定 5 节），可添加 45 分钟等短课（如新增「书香校园」）；课次值日人数支持填 0 表示不排值日；
> ④**周次支持区间** —— 课次的「具体周次」可写 `6-13` 这样的区间（此前会被截成第 6 周、第 7~13 周不显示该课次）；
> ⑤**值日人数显示** —— 课表详情显示真实人数，填 0（不排值日）的课次不再显示为 2 人；
> ⑥**两处显示修正** —— 首页今日课次课程名称对齐；网页管理后台「第 x 节」不再折行。
>
> **云函数**：本版云函数**已全部部署生效**（13 个函数，含 common/week 状态机与周次解析、admin-web、course、schedule、cron-weekly 等；数据库已加 `class.main_room` 列并设为 410，并修正了 1 条课次的区间周次）。**前端需在微信开发者工具「上传」**（上传前先点一次「编译」）。
> 门禁 **84/84 全绿**（新增 `check-period-count.js` 24 项含变异自证；`check-schedule-generate-runtime` 新增 D6 用例钉死「duty_count=0 不排值日」；e2e 75 项全绿）。

## ⚠️ 提审前必做：mp 后台「审核备注」填这段 + 为本次提审重新开启审核体验入口

（说明：每个版本都要走审核，所以审核体验入口需为本次提审**重新开启**。建议换**新**口令，不要复用上一版 `LXQ-N7K2-4M9X-P6W3-8R`。）

审核驳回原文要求「在首页填写有效账号及密码」。本小程序**没有账号密码体系**（采用「班级口令 → 名单选人 → 学号后 4 位」绑定），
故继续提供**审核体验入口**：审核员在首页「审核体验入口」输入下列口令即可一键进入**体验账号**（完整功能可体验）。

请把下面整段复制到 mp 后台本次提审的**审核备注 / 体验账号**栏位：

```
体验入口：首页底部「审核体验入口」
体验口令：LXQ-P4V8-7T3M-K5N2-9W6B
说明：本小程序为班级内部管理工具，常规绑定需班级口令与本人学号，审核员无法自行获取；
      故提供上述审核体验入口，输入口令后可进入体验账号，值日表、课表、请假、排班等主要功能均可完整体验。
      该入口仅在审核期间开启，审核通过后即行关闭（且本口令仅本次提审有效，下次提审前须换新口令）。
```

开启体验入口（在线上库执行，class id=3；口令用上面新值；并给演示账号打「演示态」标记）：

```sql
UPDATE `class` SET review_demo_on = 1, review_demo_code = 'LXQ-P4V8-7T3M-K5N2-9W6B' WHERE id = 3;
UPDATE member SET is_review_demo = 1 WHERE id = 69;   -- 体验超管（000000000091）
```

> 🛡️ **演示态行为**（1.0.6.4 已落地的安全口径，本版沿用）：审核员进入后，值日与换班、课表查看与编辑、请假登记、排班、通知等**所有主功能可完整体验**；仅对「删成员 / 停用 / 解绑他人 / 授予职位 / 班级管理 / 清空通知 / 发全员公告 / 课表全量导入」等**破坏性动作**会提示「演示模式：该操作不会真实执行」（**不会改动任何真实数据**）。降权但不缺功能。
>
> ⚠️ 口令**不要**写进小程序前端（会随包泄露），只填在 mp 后台 + 上面的 `class.review_demo_code`。**审核通过后必须关闭**，见文件末尾「关闭方式」。

## 版本 A：提审版（mp 后台「版本描述」用，功能枚举、言简）

1. 值日状态口径调整：一节课结束后 10 分钟即自动标记为「已值日」，不再需要等待下一节课开始；下午无课时段也能正常显示已完成状态，避免长时间停留在「进行中」。
2. 班级新增「主教室」配置：网页管理后台可为每个班设置主教室，保洁值日的房间以该配置为准（周一至周五、周四的打扫与周二的大扫除自动同步），更换主教室后历史值日记录同步显示新房间。
3. 课表大节数放开限制：由固定 5 节改为跟随班级时间设置，可添加 45 分钟等短时课程（如新增「书香校园」）；课次的「每节值日人数」支持填写 0，表示该课次不参与值日排班。课表网格行数随周次自适应：平时仍显示五节大课，仅当该周确有短课安排时才多显示对应行，不再出现整行空格子。
4. 显示修正：首页「今日课次」的课程名称左对齐，长短课时不再错位；网页管理后台课程表「第 x 节」不再折行。
5. 课次的「具体周次」支持区间写法（例如填写 6-13 表示第 6 至第 13 周），此前区间写法只取到起始周、其余周不显示该课次。
6. 课表详情中的「每节值日人数」按实际配置显示，设置为 0（不参与值日）的课次不再显示为 2 人。
7. 值日页移除每天下方的「+ 加值日生」快捷入口，该操作由每行右侧的「调整」承担。
8. 本次为功能更新，服务端已同步上线，审核体验入口沿用既有机制，提审前重新开启并更换新口令，审核通过后即关闭。
