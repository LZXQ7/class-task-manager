## 版本 A：提审版（mp 后台「版本描述」用，功能枚举、言简）

1. 移除从未生效的「添加值日到系统日历」「值日微信提醒」入口，以及首页右下角「打开微信通知页」悬浮胶囊（相关提醒链路此前未打通，保留会造成误导）。
2. 「我的」页头像支持点击更换微信头像：点击即调起微信头像选择，隐私拒绝时不再报错（此前透明按钮叠层在真机偶发收不到点击）。
3. 管理后台新增「使用统计」页：按功能/页面统计浏览与点击次数、使用人数，支持近 7 天 / 近 30 天 / 全部时间范围，并提供每日活跃总览柱状图。
4. 本次为功能更新，服务端已同步上线，审核体验入口沿用既有机制，提审前重新开启并更换新口令，审核通过后即关闭。
5. 值日页去掉「按日 / 按人」切换，仅保留按日视图，操作更聚焦。
6. 手动排版放开重复排班：当天或当周已有值日的人员也可再次被安排（仍保留同课次同周不重复、分组与请假三条规则）。

## ⚠️ 提审前必做：mp 后台「审核备注」填这段 + 为本次提审重新开启审核体验入口

（说明：每个版本都要走审核，所以审核体验入口需为本次提审**重新开启**。1.0.6.8 起入口改为超管开关：**「我的 → 审核体验入口」点「开启」，系统自动随机生成新口令**（旧口令当场作废）——不要复用上一版口令，也不要手写口令。）

审核驳回原文要求「在首页填写有效账号及密码」。本小程序**没有账号密码体系**（采用「班级口令 → 名单选人 → 学号后 4 位」绑定），故继续提供**审核体验入口**：审核员在首页「审核体验入口」输入当前口令即可一键进入**体验账号**（完整功能可体验）。

请把下面整段复制到 mp 后台本次提审的**审核备注 / 体验账号**栏位（口令从小程序开关弹层里复制，**不要手打**）：

```
体验入口：首页底部「审核体验入口」
体验口令：（超管在小程序内开启开关后，从弹层复制当前口令）
说明：本小程序为班级内部管理工具，常规绑定需班级口令与本人学号，审核员无法自行获取；
      故提供上述审核体验入口，输入口令后可进入体验账号，值日表、课表、请假、排班等主要功能均可完整体验。
      该入口仅在审核期间开启，审核通过后即行关闭（且每版提审前须重新开启换新口令）。
```

### 审核通过后：关闭体验入口（务必执行）

否则等于在公网留了一个「知道口令就能当超管」的通道：

```sql
UPDATE `class` SET review_demo_on = 0, review_demo_code = '' WHERE id = 3;
UPDATE member SET is_review_demo = 0, openid = NULL WHERE id = 69;   -- 体验超管（000000000091）
```

关闭后：首页不再渲染「审核体验入口」（`wx:if="{{reviewOn}}"` 恒假），线上表现与既往关闭态一致。
