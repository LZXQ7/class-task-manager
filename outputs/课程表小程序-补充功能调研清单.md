# 课程表小程序（大学生版）· 功能清单与价值说明

> 口径（2026-11-02 重新界定）：受众定位**大学生**，排除中小学家校类低龄功能（**相册 / 接龙 / 红花奖励**等一律不要）；**保留倒数日**；把"课表增强"作为产品核心差异化明确界定；并补齐适合大学生日常与学习向的实用功能。
> 第一点「当前课程高亮」已落地并入库（见 HANDOFF 2026-11-02 本 session），作为本清单的基线能力。
> 来源：GitHub 开源校园/课程表小程序（云小智、我的衡师、in-glut、ToGo校园、SYLU-EOA、WXClassTable、无广课程表、WeNjtech、NKUStudy、studyroom、LostAndFoundOnCampus、Campus_Trading_System、Books-Recycling 等）。

## 二、"课表增强"明确定义

**定义**：在"能看 / 能导入课表"的基础之上，把课表从静态表格升级为覆盖**上课前 → 上课中 → 上课后**全链路的**学习调度中枢**。围绕四个维度做增强：

- **时间维度**：现在（正在上哪节）、今天（几节课 / 状态）、本周（第几周 / 单双周）、学期（校历 / 考试）。
- **空间维度**：教室定位、没课时推荐自习室。
- **个人备忘维度**：每门课可记教师 / 地点 / 考试 / DDL。
- **选课维度**：冲突检测，选课前预审。

## 五、UGC 合规提示（沿用）

> 本应用过审对内容安全敏感。任何用户生成内容（S5 课程评价、L5 失物、L6 二手、U1 校园圈、U2 找人）都必须前置合规：

1. **内容安全接口必接**：文本 `msgSecCheck`、图片 `imgSecCheck`（云开发内置），先审后放或实时拦截。
2. **闭环而非广场**：UGC 限定班级 / 校内可见，不做公开大广场。
3. **举报 + 删除通道**：必备，UGC 类目硬性要求。
4. **隐私授权**：失物含人脸 / 定位需授权；通讯录仅展示已绑定成员。
5. **类目谨慎**：定位「教育-工具」，UGC 作附加能力，避免误选「社交 / 社区」重资质类目。

## 六、落地优先级建议

- **纯前端 / 零后端（最快发，稳日活）**：E1–E6、倒数日、S4、S8、U2 — 可随下一前端版本直接上。
- **轻后端（云函数 + 云库，复用班级隔离）**：E7/E9/E10、S1/S2/S5/S6/S7、L2/L4/L5 — 价值高，第二批。
- **UGC 红线（必接内容安全，审核重点）**：S5、L5、L6、U1 — 放最后，上线前单独做内容安全验收。
- **高门槛（依赖教务 / 图书馆凭证）**：S3、L3、S9 — 视本校数据可得性决定，优先级靠后。

> 建议路线：先发「课表增强 + 倒数日 + 纯前端学业工具（GPA 计算器 / 校历）」稳住基础体验，再上「空教室 / 自习预约 / 选课助手 / DDL 提醒」做学习刚需，最后谨慎上 UGC（失物 / 二手 / 校园圈）并过内容安全。
