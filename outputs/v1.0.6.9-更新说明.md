# v1.0.6.9 更新说明（课表编辑与周次细节 + 值日页精简）

> 覆盖范围：**1.0.6.8 → 1.0.6.9**（2026-10-15）的用户可感知改动：
> ①**课表页可直接编辑课次** —— 课程名、教师、教室、星期、大节、每节值日人数都能改，不必删除重加；
> ②**课表行数随周次自适应** —— 平时显示五节大课，只有当某周确实排到短课时才多显示该行，不再出现整行空格子；
> ③**周次支持区间写法** —— 课次的「具体周次」可写 `6-13`，此前会被只取起始周、其余周不显示该课次；
> ④**短课归入时间重叠的大节** —— 45 分钟的「书香校园」与既有大节同时段时并入那一节，一格显示两门课属预期；
> ⑤**值日页精简** —— 移除每天下方的「+ 加值日生」快捷入口，补人由每行右侧「调整」承担；
> ⑥**班费弹层去重** —— 移除重复的「仅查看，无法修改或删除」灰底横幅（弹层标题已注明身份）。
>
> **云函数**：`course` / `admin-web` / `common` 等已部署生效。**前端需在微信开发者工具「上传」**（上传前先点一次「编译」）。
> 门禁 **84/84 全绿**。

## ⚠️ 提审前必做：mp 后台「审核备注」填这段 + 为本次提审重新开启审核体验入口

（说明：每个版本都要走审核，所以审核体验入口需为本次提审**重新开启**。建议换**新**口令，不要复用上一版。）

审核驳回原文要求「在首页填写有效账号及密码」。本小程序**没有账号密码体系**（采用「班级口令 → 名单选人 → 学号后 4 位」绑定），
故继续提供**审核体验入口**：审核员在首页「审核体验入口」输入下列口令即可一键进入**体验账号**（完整功能可体验）。

请把下面整段复制到 mp 后台本次提审的**审核备注 / 体验账号**栏位：

```
体验入口：首页底部「审核体验入口」
体验口令：LXQ-R7K3-9M2V-5T8Q-X4W6
说明：本小程序为班级内部管理工具，常规绑定需班级口令与本人学号，审核员无法自行获取；
      故提供上述审核体验入口，输入口令后可进入体验账号，课表、值日、请假、排班、班费等功能均可完整体验。
      该入口仅在审核期间开启，审核通过后即行关闭（且本口令仅本次提审有效，下次提审前须换新口令）。
```

开启体验入口（在线上库执行，class id=3；口令用上面新值；并给演示账号打「演示态」标记）：

```sql
UPDATE `class` SET review_demo_on = 1, review_demo_code = 'LXQ-R7K3-9M2V-5T8Q-X4W6' WHERE id = 3;
UPDATE member SET is_review_demo = 1 WHERE id = 69;   -- 体验超管（000000000091）
```

> 🛡️ **演示态行为**（1.0.6.4 已落地的安全口径，本版沿用）：审核员进入后，课表与值日、请假登记、排班、通知、班费等**所有主功能可完整体验**；仅对「删成员 / 停用 / 解绑他人 / 授予职位 / 班级管理 / 清空通知 / 发全员公告 / 课表全量导入」等**破坏性动作**会提示「演示模式：该操作不会真实执行」（**不会改动任何真实数据**）。降权但不缺功能。
>
> ⚠️ 口令**不要**写进小程序前端（会随包泄露），只填在 mp 后台 + 上面的 `class.review_demo_code`。**审核通过后必须关闭**，见文件末尾「关闭方式」。

## 版本 A：提审版（mp 后台「版本描述」用，功能枚举、言简）

1. 课表页新增编辑课次功能：课程名称、教师、教室、上课星期、所在大节与每节值日人数均可直接修改并保存，无需删除后重新添加。
2. 课程表页右下角加号对所有人均为添加个人选修课（仅自己可见，管理员与管理员身份一致）；课程的新增与修改统一在网页管理后台完成。
3. 首页今日课次与明日课次并入本人的选修课：仅本人可见，今天有课的显示在今日课次、明天有课的显示在明日课次，课程后标注「选修」以便与全班课程区分。
4. 课表网格行数随周次自适应：平时显示五节大课，仅当该周确有短时课程安排时才显示对应行，不再出现整行空格子。
5. 课次的指定周次支持区间写法（例如填写 6-13 表示第 6 至第 13 周），此前区间写法只取到起始周、其余周不显示该课次。
6. 短时课程与既有大节时间重叠时归入该大节展示，例如四十五分钟的「书香校园」与第四节同时段时同格显示，属预期表现。
7. 值日页移除每天下方的「加值日生」快捷入口，需要补人时使用每行右侧的「调整」。
8. 班费弹层移除重复的「仅查看，无法修改或删除」提示条，弹层标题已注明当前身份。
9. 本次为功能更新，服务端已同步上线，审核体验入口沿用既有机制，提审前重新开启并更换新口令，审核通过后即关闭。
